# Eventify Frontend

This project is a client-side web application developed for visualizing an event management database.

## Features
- CSV-based data loading (Events, Sessions, Tickets, Participants)
- Dynamic event selection
- Session and ticket summaries
- Participant search functionality
- Fully client-side (no backend required)

## Technologies
- HTML
- CSS
- Vanilla JavaScript
